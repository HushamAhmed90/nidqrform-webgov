# استمارة البطاقة الوطنية — نسخة الموبايل

تطبيق ويب (PWA) لتعبئة استمارة البطاقة الوطنية العراقية من الموبايل مباشرة.

- تعبئة الاستمارة خطوة بخطوة (7 خطوات) بالعربي أو الكوردي.
- حفظ تلقائي للبيانات على جهاز المستخدم فقط (localStorage).
- حفظ الاستمارة كصورة PNG أو PDF بحجم A4، أو طباعتها مباشرة.
- يمكن تثبيته على الشاشة الرئيسية ويعمل بدون إنترنت بعد أول فتح.

## النشر
ارفع التغييرات إلى GitHub وسيقوم Vercel بالنشر تلقائياً. يجب أن يعمل الموقع على HTTPS حتى يعمل التثبيت والعمل بدون إنترنت.

عند تعديل أي ملف لاحقاً غيّر قيمة `CACHE` في `sw.js` (مثلاً `nid-form-v3`) حتى تصل التحديثات لمن ثبّت التطبيق.
